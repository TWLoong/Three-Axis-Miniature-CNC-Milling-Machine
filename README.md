## Three-Axis-Miniature-CNC-Milling-Machine
三轴微型数控铣床结构设计与优化

## 项目简介
本项目对三轴微型数控铣床进行了结构设计

## 软件平台
1.SolidWorks

2.大国工匠

3.米思米

## 注意
图纸仅包含需加工零件，标准件可根据模型的参数自行购买

## 待优化
1.部分结构设计不合理或是无法满足稳定固定的需求，需要重新设计部分零件结构或固定方式

2.加工图纸形位公差及尺寸公差设计不合理
